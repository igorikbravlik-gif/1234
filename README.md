# GEOMETRY DASH для M5StickC PLUS2

Отдельный проект, не связан с NEXUS OS. Прошив его, вы замените то, что сейчас
на устройстве; чтобы вернуться к NEXUS OS, залейте его esp32fw.bin так же, как этот.

Экран горизонтальный (240x135). Используются только кнопки A и B,
кнопка C (питание) в игре не задействована.

## Почему не JavaScript
Готовой сборки Espruino (или другой JS-среды) под M5StickC PLUS2 нет: отсутствует
поддержка экрана ST7789V2, кнопок и разметки флеша именно этой платы, а
портировать среду - отдельная большая задача, не относящаяся к игре. Игра
написана на C++ (Arduino framework + M5Unified), так она отрисовывается без
просадок кадра и использует тот же проверенный способ сборки и прошивки,
что и NEXUS OS.

## Управление
- Меню: B - следующий пункт, A (клик) - выбрать.
- Выбор уровня: B - следующий уровень, A (клик) - играть, A (долгое) - назад.
- Настройки (яркость): B - следующее значение, A (долгое) - назад.
- Рекорды: A или B - назад.
- Игра: A (клик) - прыжок, A (долгое) - пауза.
- Пауза: A (долгое) - продолжить, B - выйти в меню.
- Смерть/победа: B - заново, A (долгое) - в меню.

## Сборка без VS Code (GitHub Actions)
1. Создайте репозиторий на github.com.
2. Загрузите в него содержимое этой папки целиком, включая .github.
3. Вкладка Actions -> Build Geometry Dash -> Run workflow.
4. Когда сборка позеленеет, откройте её и скачайте артефакт esp32fw (zip),
   внутри esp32fw.bin.

## Сборка в VS Code (если есть PlatformIO)
Откройте именно эту папку (ту, где лежит platformio.ini) и соберите обычным
способом. esp32fw.bin появится в корне проекта после сборки.

## Прошивка
Через https://espressif.github.io/esptool-js/: подключитесь к устройству,
добавьте esp32fw.bin по адресу 0x0, нажмите Program.
Либо через M5Burner (Firmware Exporter - НЕ путать с Burn: Exporter считывает
прошивку с устройства, а не записывает).

## Как менять уровни и препятствия
Все данные уровней - в src/levels.cpp: три массива Obstacle на уровень
(spikes, blocks, gaps), координата x - в пикселях от старта уровня.
- Spike (шип): {x, ширина, высота} - смертелен при касании.
- Block (блок): {x, ширина, высота} - можно запрыгнуть сверху, удар сбоку - смерть.
- Gap (яма): {x, ширина, 0} - нужно перепрыгнуть, иначе падение и смерть.
Длина уровня (поле length в Level) должна быть больше координаты последнего
препятствия. baseSpeed/maxSpeed задают стартовую и предельную скорость.
